# 🌐 Repositório de Estudos: Redes de Computadores

Bem-vindo ao repositório dedicado aos seus estudos de **Redes de Computadores**! Este espaço foi estruturado para consolidar o conteúdo da sua cadeira universitária e servir de base para o seu domínio teórico e prático (do básico ao avançado).

---

## 📁 Estrutura do Repositório

- 📄 [ROADMAP.md](./ROADMAP.md) - Trilha de estudos completa, detalhada por módulos e camadas (OSI / TCP-IP).
- 📚 [FONTES_RECOMENDADAS.md](./FONTES_RECOMENDADAS.md) - Recomendações dos melhores livros (Kurose, Tanenbaum, Stevens), sites, ferramentas e canais do YouTube.
- 🔐 [.env](./.env) - Chaves de integração com o Trello (configuradas e ignoradas no .gitignore).
- 🤖 [trello_board_creator.py](./trello_board_creator.py) - Script em Python para gerar e sincronizar automaticamente um quadro Kanban de estudos no seu Trello.

---

## 🚀 Como Estudar com a IA (Metodologia Ativa)

1. **Apresentação de Conteúdo & Analogias**: Traga o assunto da aula ou do livro e peça para explorarmos a fundo.
2. **Quizzes e Fixação**: Peça baterias de testes no modelo da sua faculdade (múltipla escolha, verdadeiro/falso e dissertativas).
3. **Desafios Práticos**: Simulação de cálculo de sub-redes IPv4, análise de cabeçalhos Wireshark e resolução de problemas de rede (troubleshooting).
4. **Sincronização com o Trello**: Para criar ou atualizar seu quadro Kanban de estudos, execute:
   ```bash
   python trello_board_creator.py
   ```
